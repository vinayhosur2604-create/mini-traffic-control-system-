# 🚦 Smart Traffic Control System (Arduino)

This project is a mini smart traffic control system built using Arduino and an ultrasonic sensor. It dynamically adjusts traffic signal timing based on vehicle density, helping reduce congestion and improve traffic flow.

## 📌 Overview
Traditional traffic lights operate on fixed timers, which can lead to unnecessary waiting time. This project introduces an intelligent system that detects vehicles using an ultrasonic sensor and adjusts signal duration accordingly.

## ⚙️ Features
- 🚗 Detects vehicle presence using ultrasonic sensor
- ⏱️ Dynamic signal timing based on traffic density
- 🚦 LED-based traffic light simulation (Red, Yellow, Green)
- 🔌 Simple and cost-effective design
- 🧠 Beginner-friendly Arduino project

## 🛠️ Components Used
- Arduino UNO
- Ultrasonic Sensor (HC-SR04)
- LEDs (Red, Yellow, Green)
- Resistors
- Breadboard & Jumper Wires

## 🔌 Working Principle
- The ultrasonic sensor measures the distance to nearby vehicles.
- If vehicles are detected close to the sensor (high traffic), the green signal duration increases.
- If no vehicles are detected (low traffic), the signal switches faster.
- This ensures efficient traffic management.
